# Laundry Services Web App

A JavaScript DOM based web application for a laundry service. Users can
explore services, add items to a cart, book appointments, and receive an
email confirmation. The page includes a navigation bar, hero section,
service overview, booking system, quality description, newsletter
subscription, and footer.

## Features
- Responsive navigation bar with logo, Home/Services/About Us/Contact Us
  links, and the user's name on the right.
- Hero section with a "Book a Service Today" button that scrolls to the
  booking section.
- Service overview band showing 15+ laundry services, 240+ happy customers,
  and 2+ years of experience.
- Booking section with a service list (Add Items / Remove Now) and a cart
  with dynamic total amount.
- Booking form with EmailJS based confirmation email support.
- Quality description section (premium services, quick support, timely
  delivery, affordable prices).
- Newsletter subscription section.
- Footer with logo, about us, important links, contact, and social icons.

## Files
- `index.html` - main page layout
- `style.css` - styling for the page
- `script.js` - interactive behaviour
- `README.md` - project information
- `images/` - service images

## How to Use
1. Open `index.html` in any browser.
2. Click **Add Items** to add a service to your cart.
3. Click **Remove Now** to remove a service from your cart.
4. Fill in your details and click **Book Now**.
